🌡️ Temperature Monitoring System

A simple Temperature Monitoring System designed to measure and monitor the surrounding temperature using a temperature sensor. The system displays the real-time temperature value and can be used for basic environmental monitoring applications.

Features:

🌡️ Real-time temperature monitoring
📟 Displays temperature readings
🔌 Simple and low-cost hardware setup
🛠️ Easy to build and understand
💡 Useful for learning sensor interfacing and embedded systems

Technologies/Components:

Arduino
Temperature Sensor (LM35)
LCD/Serial Monitor
Jumper Wires
Breadboard

Application:
This project can be used in basic environmental monitoring, electronic systems, and as a beginner-level embedded systems project.
